# 🚰 Sabbela - Smart Home Water Usage Monitoring System

A smart home system designed to monitor real-time water usage, prevent data loss through stable hardware architectures, and provide tracking via a mobile app.

---

### 🛠️ Key Features & Technical Details
- **Wired Hardware Architecture:** Central microcontroller setup engineered to prevent data loss from connection drops or local power outages.
- **Real-Time Data Processing:** Under-sink flow sensors logging local data efficiently.
- **Mobile Interface:** android application for tracking daily/monthly consumption metrics.

---

### 💻 Technologies Used
- **Mobile:** Android Studio
- **Hardware/Embedded:** Microcontroller programming (C/C++), ESP32,flow sensors
- **Backend/Database:** Firebase

---

### 📂 Repository Structure
- `/firmware`: Embedded code for microcontrollers and sensors.
- `/mobile_app`: Source code for the Android monitoring application.
